# Wingman 3.0.0

Wingman 3.0.0 is a local Telegram relationship assistant with memory, planning, voice transcription, temporary attachment handling, and a transparent dashboard.

## Highlights

- Natural memory capture with notes, evidence, retrieval, confirmation, editing, and deletion cards
- Planning tools for places, saved ideas, events, and reminders
- Telegram cards for planning records with readable details and delete controls
- Voice messages transcribed with `gpt-4o-mini-transcribe`
- Temporary attachment metadata with no persistent audio storage
- API diagnostics with full request and response inspection
- Retrieval inspection with query details, candidate text, ranking information, and source links
- Responsive dashboard with refined memory, planning, settings, and conversation layouts
- Owner-editable static conversation guidance
- Local settings, pause and resume controls, JSON import and export, backups, and safe updates
- Dashboard favicon package and branded README banner

## Validation

The release was validated with Ruff, formatting checks, mypy, the complete pytest suite, and repository diff checks.
