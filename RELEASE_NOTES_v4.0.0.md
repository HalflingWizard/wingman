# Wingman 4.0.0

Wingman 4.0.0 improves local configuration, dashboard readability, planning cleanup, and video understanding.

## Highlights

- City search now uses geocoding results to select a matching IANA timezone.
- The dashboard content has a fixed readable width and long conversation content wraps correctly.
- Health no longer repeats repository commit information already shown elsewhere.
- Health persistence checks permanently remove their temporary planning records.
- Deleted and cancelled planning records are hidden by default, with an option to show them.
- Videos without speech now explicitly tell the model to rely on the five sampled frames.
- Rolling summaries are prompted as structured internal continuity notes instead of copied messages.
- The application and documentation version is now 4.0.0.
