# Wingman 4.3.0

Wingman 4.3.0 completes the operational logging and release hardening work for the 4.x line.

## Highlights

- Added a live runtime output panel to the dashboard Logs page.
- The live panel refreshes automatically and keeps the latest 100 safe operational lines.
- Added date and text filtering for durable runtime errors.
- Runtime failures now appear in the live output and remain available in durable error history.
- Detailed errors remain scrollable, copyable, and redacted.
- Dashboard diagnostic views remain bounded to the latest 100 records.
- Completed release hardening with automated tests, lint, formatting, type checks, and diff checks.
